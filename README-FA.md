# ARZ-NET Kotlin Android App

اپ تیره اندرویدی با Kotlin و Jetpack Compose برای نمایش قیمت‌های بازار از طریق ARZ-NET Cloudflare Worker:
- دلار آزاد
- سکه امامی
- طلای ۱۸ عیار (گرم)
- تتر

API: https://arznet-api.ahad-ronaghi66.workers.dev/quotes/current

این اپ هر بار که باز می‌شود قیمت‌ها را می‌گیرد و هنگام باز بودن، هر ۶۰ ثانیه تازه‌سازی می‌کند. دکمه «به‌روزرسانی» برای دریافت دستی است. اپ از ساختار JSON جدید Worker استفاده می‌کند. وضعیت تازگی هر منبع در API موجود است؛ این نسخه قیمت‌ها را نمایش می‌دهد و برای جلوگیری از نمایش داده قدیمی، وضعیت freshness باید در توسعه بعدی به رابط کاربری اضافه شود.

برای ساخت APK، پوشه را در Android Studio باز کنید، Gradle Sync را انجام دهید و از Build > Build APK(s) استفاده کنید. پیش‌نیاز JDK 17 است.

## ساخت خودکار APK با GitHub Actions
1. کل محتوای این پروژه را به یک مخزن GitHub جدید آپلود کنید.
2. از تب **Actions**، workflow با نام **Build ARZ-NET APK** را انتخاب کنید.
3. روی **Run workflow** بزنید؛ یا با push به شاخه `main` ساخت خودکار آغاز می‌شود.
4. پس از موفقیت، وارد اجرای workflow شوید و از بخش **Artifacts** فایل `ARZ-NET-debug-APK` را دانلود کنید.
5. فایل ZIP دانلودی را باز کنید و `app-debug.apk` را روی گوشی نصب کنید.

این خروجی debug است و برای نصب شخصی/آزمایشی مناسب است؛ برای انتشار عمومی، نسخه release امضاشده جداگانه لازم است.
