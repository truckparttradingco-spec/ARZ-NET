
# ARZ-NET | اپلیکیشن اندروید

اپلیکیشن اندرویدی ARZ-NET با استفاده از Kotlin و Jetpack Compose برای نمایش قیمت‌های بازار آزاد.

## امکانات برنامه

- نمایش قیمت دلار آزاد
- نمایش قیمت طلای ۱۸ عیار (هر گرم)
- نمایش قیمت سکه امامی
- نمایش قیمت تتر (USDT)
- دریافت خودکار قیمت‌ها هنگام باز شدن برنامه
- به‌روزرسانی خودکار قیمت‌ها هر ۶۰ ثانیه هنگام باز بودن برنامه
- امکان به‌روزرسانی دستی از طریق دکمه به‌روزرسانی
- رابط کاربری تیره و فارسی
- ویجت صفحه اصلی اندروید

## API دریافت قیمت‌ها

API اصلی برنامه:

https://arznet-api.ahad-ronaghi66.workers.dev/quotes/current

## ویجت صفحه اصلی اندروید

ویجت ARZ-NET برای مشاهده سریع قیمت‌ها بدون نیاز به باز کردن برنامه طراحی شده است.

امکانات ویجت:

- نمایش قیمت دلار آزاد
- نمایش قیمت طلای ۱۸ عیار
- نمایش قیمت سکه امامی
- نمایش قیمت تتر
- دکمه به‌روزرسانی مستقل
- باز کردن برنامه با لمس بدنه ویجت
- امکان تغییر اندازه ویجت
- به‌روزرسانی دوره‌ای توسط سیستم اندروید و WorkManager

### نحوه افزودن ویجت

1. صفحه اصلی گوشی را لمس طولانی کنید.
2. وارد قسمت Widgets یا ویجت‌ها شوید.
3. ویجت ARZ-NET را پیدا کنید.
4. آن را روی صفحه اصلی قرار دهید.

برای دریافت فوری قیمت‌ها، دکمه رفرش ویجت را لمس کنید.

## پیش‌نیازهای ساخت

- Android Studio
- JDK 17
- Android SDK مطابق تنظیمات پروژه
- اتصال اینترنت برای دریافت وابستگی‌های Gradle

## ساخت APK با Android Studio

1. پروژه را در Android Studio باز کنید.
2. منتظر بمانید Gradle Sync کامل شود.
3. از منوی Build گزینه Build APK(s) را انتخاب کنید.
4. پس از پایان ساخت، فایل APK را از مسیر خروجی نمایش‌داده‌شده دریافت کنید.

## ساخت خودکار APK با GitHub Actions

پروژه از GitHub Actions برای ساخت خودکار APK پشتیبانی می‌کند.

مراحل:

1. پروژه را در مخزن GitHub قرار دهید.
2. وارد بخش Actions مخزن شوید.
3. Workflow مربوط به Build ARZ-NET APK را انتخاب کنید.
4. برای اجرای دستی، روی Run workflow بزنید.
5. منتظر بمانید فرایند Build با موفقیت تمام شود.
6. وارد اجرای موفق Workflow شوید.
7. از قسمت Artifacts فایل خروجی APK را دانلود کنید.
8. فایل ZIP را باز کنید و APK را روی گوشی نصب کنید.

### نوع خروجی

خروجی فعلی Debug است و برای آزمایش و استفاده شخصی مناسب است.

برای انتشار عمومی در Google Play یا توزیع رسمی، باید نسخه Release با کلید امضای معتبر ساخته شود.

## مجوز اینترنت

برنامه برای دریافت قیمت‌ها به اتصال اینترنت نیاز دارد. مجوز INTERNET باید در AndroidManifest.xml تعریف شده باشد.
